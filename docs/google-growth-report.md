# تقرير: تحسين انتشار AZRAR عبر Google | Report: Google reach improvements
التاريخ | Date: 2026-11-09 · الفرع | Branch: `feat/seo-conversion-google`

## 1. ما تغيّر | What changed
1. **تصحيح ادعاء «بدون إنترنت»** في 48 ملفاً (عناوين، أوصاف، JSON-LD، FAQ، `llms.txt`، `pricing.md`، `chatbot.js`، التذييل). الصياغة الجديدة: «يتطلب التفعيل اتصالاً بالإنترنت، ثم التحقق من الترخيص مرة كل 7 أيام على الأقل»؛ البيانات محلية.
   Offline claims corrected everywhere; data stays local, activation + 7-day license check need internet.
2. **الصفحة الرئيسية:** عنوان/وصف/H1 حول إدارة العقارات والإيجارات والأقساط؛ زر Microsoft Store أساسي بنص صريح؛ سطر متطلبات (Windows 10/11 64-bit، تجربة 30 يوماً، ترخيص بعد التجربة، التفعيل يحتاج إنترنت)؛ أزرار الباقات صارت «اطلب الترخيص عبر واتساب» لا «ابدأ مجاناً».
3. **39 صفحة فيها كتلة `cta`:** زر Store أساسي + واتساب ثانوي للأسئلة وطلب الترخيص + ملاحظة التجربة والترخيص.
4. **JSON-LD:** حُذف `softwareVersion` (3.16.1 قديم، والإصدار المنشور في المتجر غير مؤكد)، وصف دقيق. الأسعار (49/79/119 USD) تطابق الصفحة.
5. **hreflang:** أُزيل `hreflang="en"` → `/?lang=en` من الرئيسية و`sitemap.xml` لأنه نفس ملف HTML بتبديل JavaScript وليس صفحة إنجليزية مستقلة. صفحات الأردن/الخليج/الميزات لها نسخ `-en` مستقلة وتبقى.
6. **sitemap.xml:** `lastmod` = 2026-11-09 للصفحات التي تغيّر محتواها فعلاً (كلها تقريباً بسبب التذييل).
7. **القياس:** ملف `track.js` موحّد: `store_click`, `trial_lead`, `whatsapp_click`, `email_click` بمعاملات `destination` + `placement` + `page_lang` فقط (لا رابط، لا هاتف، لا بريد، لا نص رسالة). إرسال `gtag('js')`/`config` فوراً على الرئيسية بحيث لا تضيع نقرة أول تفاعل (التحميل الشبكي فقط مؤجل).

## 2. الفحوصات | Checks (نتائج فعلية)
- كل JSON-LD يُحلَّل (`json.loads`)؛ `sitemap.xml` يُحلَّل وكل `<loc>` له ملف؛ لا روابط داخلية مكسورة؛ لا بقايا لادعاء «offline» (فحص نصي)؛ `node` يفحص صياغة `track.js` و`chatbot.js`.
- اختبار الأحداث في المتصفح: نقرة المتجر/الباقة/واتساب/البريد = حدث واحد لكل نقرة بالمعاملات الثلاث فقط. ملاحظة: الفحص تم على لقطة ثابتة مع حقن `track.js`، **ولم يُفحص CSS/الجوال بصرياً بشكل موثوق**.
- لم يُختبر التحميل الفعلي إلى GA4 (DebugView) ولا حاوية GTM.

## 3. محجوب أو غير مؤكد | Blocked / unverified
- **Search Console:** إضافة Claude in Chrome غير متصلة، فلا خط أساس (ظهور/نقرات/فهرسة) ولا إرسال sitemap ولا طلب فهرسة. تُنفَّذ بعد الدمج.
- **GA4 / GTM:** لم أفحص إن كانت حاوية `GTM-WXHDB8R` تحوي وسم GA4 مكرراً مع `gtag` المباشر (احتمال تكرار `page_view`). لم أحذف أي تحميل.
- **الإصدار المنشور في المتجر:** غير مؤكد (التحديث مرتبط بـ Submission 8 الذي لم ألمسه).
- **`privacy.html` سطر 189 (EN):** يقول «Activation is performed offline with a signed license file…» ويتعارض مع التفعيل/التحقق عبر الإنترنت. نص قانوني لم أعدّله؛ يحتاج قرارك.
- `chatbot.js` يذكر «مساعد ذكاء اصطناعي مدمج»؛ لم أتحقق من صحته.
- صور/فيديوهات: أُعيد استخدام الموجود فقط.
