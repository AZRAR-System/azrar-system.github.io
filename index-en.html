Before you start

Can I work offline?

Daily work in local mode does not require a permanent connection. Updates and optional integrations and sync use the network when needed.

Which devices are supported?

AZRAR is a Windows 10/11 64-bit desktop application. macOS and Linux are not currently supported.

Do I need a card or an AZRAR account?

The full 30-day trial needs no payment card. The direct installer is available without a Microsoft account.

Is the license annual or perpetual?

The listed plans are annual licenses based on device count and include updates and support during the license period. Renew to continue using the application after expiry. Confirm the renewal price when ordering.

Does my plan include SQL Server sync?

SQL Server sync is available in every plan. Licensed application device counts still depend on your plan. Sync needs a suitable server, network and setup.
